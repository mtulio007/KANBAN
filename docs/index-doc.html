📋 Documentação Técnica - KanbanClient v0.0.1

🎯 Visão Geral do Aplicativo

KanbanClient é um sistema web standalone para gerenciamento de produção industrial (Pracafé - Embalagens de Pano). Funcionalidades principais:

  • CRUD de pedidos de produção com drag & drop.
  • Rastreamento de progresso com barras visuais.
  • Previsões IA via Google Gemini.
  • Relatórios PDF customizados.
  • Gerenciamento de catálogos (produtos/clientes).
  • Sincronização híbrida LocalStorage + SQLite.

🏗️ Fluxo de Funcionamento

  1. Inicialização: Carrega SQLite orders + LocalStorage catálogos (polling 2.5s sync).
  2. CRUD: NewOrderModal → handleSaveOrder → POST SQLite + LocalStorage debounce 500ms.
  3. Drag & Drop: Reordenação visual (estado React).
  4. Progresso: Input quantidade → auto status (Pendente→Produzindo→Concluído).
  5. IA: Botão predição → Gemini analisa progresso/data → aiPrediction.
  6. PDF: Botão → HTML print-friendly → browser print dialog.

⚙️ Requisitos de Instalação

  • Node.js 18+ ou 20+ (recomendado Node 20/LTS).
  • npm 10+ (ou Yarn/Pnpm compatível).
  • Git para clonar o repositório.
  • Conexão de internet para instalar dependências.
  • Opcional: chave Google Gemini se for usar previsão IA.

🚀 Instalação & Execução

git clone 
cd KANBANCLIENT
npm install
# Crie o arquivo .env na raiz do projeto
# VITE_GEMINI_API_KEY=your_key

# Para desenvolvimento Electron local:
npm run electron:dev

# Para apenas front-end Vite:
npm run react:dev

# Para compilar arquivos Electron TypeScript antes do build:
npm run build:electron

# Para gerar versão de produção Electron:
npm run electron:build

# Ver preview do build Vite:
npm run preview

🐞 Erros Comuns e Correções

  • Unable to find Electron app ... electron/main.js
    Execute npm run build:electron antes de npm run electron:dev ou npm run electron:build.
  • Não foi possível localizar o arquivo de declaração para o módulo 'react'
    Garanta que @types/react e @types/react-dom estão instalados nas dependências de desenvolvimento.
  • Erro de compilação TypeScript em JSX
    Verifique que tsconfig.json contém "jsx": "react-jsx" e que o projeto está usando o template React correto.
  • Problema de login
    Usuários válidos atuais: Tulio / 124578 e User / User. Outros valores retornam error.
  • Falha ao gerar build
    Confirme que o arquivo tsconfig.electron.json existe e que o script build:electron foi executado.
